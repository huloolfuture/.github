# Hulool Future brand

The HF monogram: an italic **H** and **F** sharing one stroke, moving from navy to green.

| Asset | Use |
|:--|:--|
| `logo-full.jpeg` | Primary logo (monogram + wordmark) on light backgrounds. |
| `avatar-1024.png` | Social and organization avatars. Monogram only, so it stays legible at small sizes. |
| `monogram-color.png` | Monogram on light backgrounds (transparent). |
| `monogram-light.png` | Monogram on dark backgrounds (transparent). |
| `wordmark-color.png` / `wordmark-light.png` | "HuloolFuture" wordmark for light / dark backgrounds. |

## Type

## Don'ts

- Don't put the full logo (with wordmark) in small avatars — use the monogram.
- Don't place the navy monogram on dark backgrounds — use `monogram-light.png`.
- Don't recolor the monogram outside the navy → green palette.
